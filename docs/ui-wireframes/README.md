# UI Wireframes

Wireframes for the screens defined in [../ui-specification.md](../ui-specification.md). Not yet generated; this is the next deliverable after the specifications are approved.

Planned wireframes, one file per screen:

| File | Screen |
| --- | --- |
| `runs-list.*` | Runs list |
| `run-overview.*` | Run overview with the stage funnel |
| `stage-detail.*` | Stage detail with the record table |
| `record-trace.*` | Record trace across all stages |
| `field-analytics.*` | Per-field statistics and distributions |

Each wireframe should be black and white, structural, and unstyled: layout, hierarchy, and the controls on each screen, not colour or typography. Colour direction is settled later, against the palette notes in the UI specification.
